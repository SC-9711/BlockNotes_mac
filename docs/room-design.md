# 书房空间设计与视觉验收

基准：用户提供的四张 Minecraft 书房截图；方块、GUI、字体参考版本统一 Java Edition 1.21。

从约 11×9×6 起步，实际采用 11×10×6 的室内方块范围，以给默认镜头和前景地毯留出空间。后墙与侧墙完整存在，云杉主材、深色橡木框架、石砖墙脚和局部苔石砖形成层次。家具由原版半砖、楼梯、栅栏柱、盆栽、讲台与箱子比例搭建。参考图仅用于空间分析，没有贴作背景。

镜头在房间近侧偏右，能同时看见讲台正面、左箱子、中央窗户、两侧书架和桌椅。指针移动产生小幅平滑视差；编辑器和容器打开时暂停。两组书架分别绑定 main / ideas；分类数据不依赖坐标。箱子打开有铰链动画，悬停有方块边框和功能提示。

## 实体与物品栏专项核对

2026-10-09 用户指出箱子上表面与下方图标差异后，核对官方 1.21 客户端的资源与模型尺寸：

- 箱子上盖此前错误使用纹理中的内部深色区域；现为 `normal.png` 的 `(28,0)–(42,14)` 外盖木板。侧面也按实体的 UV 朝向修正，不能套用方块 JSON 的面朝向。
- 箱盖转轴为 `(0,9,1)/16`，盖为 14×5×14 像素，闭合总高 14/16；锁扣本地范围 `(7,-2,14)–(9,2,15)`。开盖按半秒线性进度与 cubic easing。
- 讲台书改为 BookModel 七部件，固定姿态由 LecternRenderer 的位置 `(0.5,1.0625,0.5)`、Y 90° / Z 67.5° 与本地 Y -0.125 组成；书页贴图不再用简化平面近似。
- 箱子 GUI 为 `[30,45,0]`，普通书架和讲台继承 `[30,225,0]`，均使用模型中的 0.625 缩放。读取实际 item / block 模型继承，不统一硬编码所有图标角度。参考 [1.21 箱子物品模型](https://mcasset.cloud/1.21/assets/minecraft/models/item/chest.json)。
- 方块图标按当前 CSS 尺寸 × 设备像素比直接渲染，取消固定 32 px 图标到 48 px 的非整数放大；像素纹理 nearest、无抗锯齿。GUI 使用独立两方向光照与原始颜色空间，避免把书房面阴影套到物品图标。
- 书与笔、命名牌是原始 16×16 PNG，保持整数缩放；指南针使用原版物品模型的默认 `compass_16`，不模拟没有玩家的世界方向。

模型事实依据官方 1.21 client / client mappings（SHA-1 分别 `0e9a07b9bb3390602f977073aa12884a4ce12431` / `0530a206839eb1e9b35ec86acbbe394b07a2d9fb`）以及 ModelPart、ChestRenderer、BookModel、LecternRenderer、Lighting 的模型参数。只实现本项目所需尺寸与渲染转换；原始客户端与研究缓存未提交。

`tests/models.test.mjs` 独立核对实际几何 UV、像素尺寸和 GUI 朝向；Electron 测试检查默认图标 48 px、窄窗 32 px，并实测四实体点击与笔记闭环。`chest-detail.png`、`hotbar.png` 是最终程序的直接截图；`room-before-entity-fix.png` 保留修正前对照。当前没有把这些软件截图称为原版游戏截图。

## 讲台、灯笼与菜单交互修正

讲台位于 `(-1,0,0)`，占一个网格足迹，直接落地，附加底座半砖已移除；地毯避开其单元。上下部分继续使用官方 lectern_base、lectern_front、lectern_sides、lectern_top、oak_planks 原始模型纹理，未统一替换为木板贴图。

三盏悬灯均在 y=4 的整数网格单元，上方 y=5 为横梁；悬挂模型链条上端到达相邻支撑底面，移除额外发光方盒。桌灯在 `(2,2,-2)`，由 y=1 的 dark_oak_slab_top 提供 y=2 完整顶面支撑；窗台盆栽也采用上半砖有效顶面。对应布局约束由模型测试核对，默认视图实体点击继续通过。

暂停菜单参照 [Minecraft 官方控制说明](https://www.minecraft.net/article/minecraft-controls) 与Java 1.21 菜单视觉布局：原版按钮、像素字体、上方标题、整行返回 / 退出与双列选项 / 指引。保留软件的实际功能，未放置成就、联机等无效菜单。背景冻结、模糊和暗化；设置滑块采用本地原版 sprites。

书与笔新增空白页保留原始书页、箭头与翻页音效；新分页节点存储于同一完整正文，空白页不是临时展示幻象。紫色边框的工具栏标签即时出现，避免浏览器慢速原生 tooltip。剩余视觉边界仍包括简化世界 lightmap、DOM 字体度量和面向笔记的次级菜单内容；没有宣称所有界面与游戏逐像素相同。

唱片机最终位于 `(1,0,-1)`，在讲台右后方、窗户前的独立地面格。沿用原版 jukebox JSON 与侧面 / 顶面纹理，物品栏解析其 GUI display。模型完整进入默认视野，避开桌腿、栏杆、地毯和其他实体；实机射线点击可打开播放器。原版唱片机没有选曲 GUI，这里的曲名列表和控制是笔记软件的次级界面，使用原版按钮 / 唱片图标 / 像素字体。

## 首页与方块光照优化（方案 2 / 3）

设置统一由 Esc → 选项进入，去掉首页按钮、常驻保存状态和选中物品名称。书页仍显示保存状态，错误仍即时提示；九格快捷栏固定，悬停物品提示保留。

原版唱片开始播放后，首页短暂显示「正在播放：作者 - 曲名」，按 Java Gui 的 HUD 布局、色彩变化和淡出时间呈现。唱片机上方采用 1.21 原始音符 PNG，而非自行绘制符号；位置、四个音高颜色、生成周期与短生命周期由已校验的官方客户端参数核对。暂停菜单冻结，停止播放消失，无开机自动播放。

旧版以距离估计且最低亮度约 0.82，墙体不阻挡光线。新版分别计算窗口天空光与四盏灯笼的光传播：封闭墙体遮挡，玻璃透光，半砖桌面和梁柱参与阴影；再烘焙到方块和实体顶点。桌底、椅底、书墙凹槽和天花梁下更暗，窗边及灯笼附近清晰可见；原版像素贴图与固定布局保持。

`room-before-home-lighting.png` / `room.png` 为同角度实机前后对照；`room-record-playing.png` 展示播放提示与音符。参考原版 Gui / NoteParticle / JukeboxSongPlayer 参数及 [Prismarine models.js](https://github.com/PrismarineJS/prismarine-viewer/blob/8a3ce60b40f1ff7a26422a8f8904fbedbe808688/viewer/lib/models.js) 的方向明暗 / AO。继续复用 Three.js、R3F、既有原版 JSON 解析；没有增加整套游戏引擎。

客观边界：光照为固定书房的静态近似，箱盖打开后沿用闭合姿态烘焙颜色；旋转元素的遮挡采用包围盒，植物不投射精确叶片阴影。没有用原版游戏渲染器计算逐像素对照，不称为完全 1:1。上述范围不影响笔记数据、功能方块点击与离线运行。

## 梯子频闪与桌面支撑修复

梯子原始模型含两张方向相反、完全共面的贴片；此前统一 DoubleSide 使它们同时参与深度绘制。原位置 z=-3.95 再叠加模型局部 z=15.2/16，恰好落在木柱 z=-3 的表面上，引发第二重深度冲突。现按原版面朝向使用 FrontSide；梯子转向房间，并补偿模型角点旋转，将实际贴片放在木柱南侧 z=-2.95，保留原版 0.05 格贴墙间隙。没有通过关闭深度检测或覆盖绘制掩盖问题。

书桌原上半砖的底面为 y=1.5，桌腿顶部为 y=1，两者留半格缝。三格桌面改为原版深色橡木完整方块，底面 y=1 与桌腿相接，顶面 y=2 继续直接承托桌灯和盆栽。家具范围、交互实体位置与笔记功能保持。

两项回归测试验证实际射线仅命中对应方向的梯子贴片，以及全部八段梯子的真实变换、宽度、支撑木柱与间隙；原有桌灯测试补验桌腿 / 桌面连接。

播放唱片时会持续按需绘制；视差镜头在进入 0.0001 收敛阈值后，精确停在目标方向，避免继续做无限小插值调整。实机验证等待镜头确实收敛，再比较梯子区域的连续截图，避免把尚在运动的视角误判为频闪。

连续帧采样期间在测试窗口临时拦截实机指针事件，防止截图过程中系统鼠标位置覆盖自动化视角；渲染、唱片播放与音符更新仍运行。五个视角各比较两处梯子区域，每处三次后续帧，共 30 次像素哈希一致。该输入隔离仅存在于验收脚本，不写入应用。近景为 ladder-fixed、desk-support-fixed；ladder-view-0 至 4 记录各视角。

## 讲台尺寸专项核对

按本地 1.21 原始 lectern JSON 经实际 buildModel 生成几何，再使用 Scene 的世界变换核对。底座为 16×2×16 像素（宽深各一方块、厚 1/8 格），立柱为 8×13×8 像素，斜面为 X 轴 -22.5°；实际世界 scale 为 `(1,1,1)`，未套用 firstperson / GUI 显示缩放。旋转后完整本体包围盒约 `1×1.15328145×1` 方块，其中顶部超出一格来自原版斜面旋转，不能强行压到一格高度。

核对脚本为 scripts/audit-lectern.mjs，当前本体尺寸正确，保留原版比例。lectern-scale-checked.png 为实机近景，lectern-audit.json 为尺寸结果（均在本地截图目录）；书本仍沿用先前核对过的原版 LecternRenderer 固定姿态。
