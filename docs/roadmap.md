# 路线图

## 当前已有

- 笔记创建、编辑、可靠保存、只读讲台、书架、检索、归档/回收及备份恢复。
- Java 1.21 固定书房与原声唱片交互，保持数据业务与场景位置解耦。
- 首次启动自动资源准备的实现、固定版本与校验基准；验收结果单独记录。
- 公开仓库文档、原创来源与许可边界、源码审查和 Windows CI。

## 发布验收

- 真实公开程序包的首次联网资源准备、失败重试、重启离线和完整笔记回归。
- 公开仓库源码与下载包不含原版素材或个人笔记；演示截图全部使用虚构数据。
- Windows ZIP、校验和、版本说明和已知问题；远程 CI 实际通过后发布。

## 后续改进

- 本机已安装资源的导入，减少首次下载；网络错误提示与缓存维护。
- 构建工具链剩余已知漏洞的兼容升级与打包回归。
- 更多显卡、不同 DPI、中文 IME 候选窗及长时间使用验证。
- 有实际需要时评估签名与安装器。

不计划引入角色漫游、联机账号、云笔记服务、合成或其他无关游戏机制。
