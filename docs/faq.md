# 常见问题

## 下载程序后能和演示一样吗？

公开 Windows 程序首次启动在本机自动准备固定 Java 1.21 原始资源。方块、道具、GUI、字体、音效和 19 张唱片与演示使用同一资源基准；校验不一致不会启用。用户自己的笔记库初始为空，演示里的学习内容不会自动写入。

资源一致不代表不同显卡、系统缩放和窗口大小的像素结果完全相同。源码预览或未验收平台不应被描述为跨所有设备完全一致。

## 需要安装 Minecraft 或开发工具吗？

打包 Windows 程序不需要 Node、npm、Java 运行时或正在运行的游戏。首次资源准备需要网络；原版资源使用权应由用户自行确认，本程序不验证游戏所有权。

## 能离线使用吗？

首次资源准备完成后，书房、编辑、保存、阅读、搜索及唱片从本机读取。程序不提供云账号和云笔记同步。已有资源缺失或被改动时会重新进入资源准备，而不是静默使用不同素材。

## 笔记保存在哪里？

默认 `%APPDATA%\blocknotes\`。数据库是 blocknotes.sqlite，资源位于 resource-packs/。Esc → 选项显示实际数据位置。程序和数据分开，更新应用不应删除数据目录。

## 为什么没有把素材放进下载包？

源码和程序可以公开，原版游戏资源的权利独立管理。首次启动只在用户本机下载校验，不把资源包作为项目的公开附件。MIT 不能授权 Minecraft 素材再分发。

## 项目免费，为什么 MIT 还允许商业使用？

作者的非商业开发目的与代码许可是两回事。MIT 明确允许商业使用并要求保留版权和许可声明；本项目不添加冲突的禁止商用条件。第三方素材和作者身份仍有独立边界，见 [COPYRIGHT](../COPYRIGHT.md)。

## 为什么讲台与书与笔不同？

书与笔用于输入、整理和编辑；讲台用于选书及只读阅读。讲台的末页不会新增空白页，阅读不会触发保存。需要修改时点击“继续编辑”。

## 删除和归档有什么区别？

归档用于暂时收起仍有价值的笔记，可继续检索；移入回收区后从普通检索隐藏，但正文保留，可以恢复。删除自定义书架只迁移笔记归属，不删除正文。
