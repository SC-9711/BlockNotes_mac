## 交付内容

- MIT 代码、锁定依赖、贡献规范、安全说明、Issue / PR 模板和 Windows 源码 CI。

- 公开 Windows 程序包不包含开发者笔记、SQLite、私人备份或原版素材。首次运行创建空笔记库；学习文案仅作为明确标注的虚构示例保留，不自动导入。
- 固定 Java 1.21，首次启动自动从官方端点获取资源并验证哈希，后台解析与字体转换，完成后原子启用。网络失败允许重试，安装与笔记数据分离。
- 历史开发仓库保留在本地；公开仓库从审查后的当前源码建立干净历史，避免把早期个人路径带入 Git 历史。

## 已知限制

- 首次使用依赖官方服务器可达性；资源准备完成后才支持完整离线体验。自动下载不验证游戏所有权，也不赋予原版资源再分发权。
- 本轮用全新应用数据目录验证冷启动，没有在另一台全新 Windows 电脑或 Windows 沙盒中验证；非 Windows、不同显卡与 DPI 仍需反馈。
- 构建未签名。资源相同不代表 Three.js 光照和 DOM 编辑排版与 Minecraft 引擎逐像素相同。
- 完整 npm audit 包含构建工具链的 8 项 moderate 提示；生产依赖为 0。暂不进行可能破坏打包链的强制升级。
- 若在资源准备过程中强制结束进程，未启用的暂存目录可能残留；已有资源指针和笔记不受影响，重启可重试。
- 模式扫描不等于完整秘密审计；二进制截图及品牌素材的来源另见 COPYRIGHT.md 与截图说明。
