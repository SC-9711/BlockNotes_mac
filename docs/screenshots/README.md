# 实机截图来源

截图由 `scripts/capture-docs.mjs` 启动真实 Windows Electron 应用生成，使用独立临时 SQLite 和 `examples/study-notes.json` 的 19 篇原创虚构文案。没有读取日常笔记库，没有使用用户提供的截图作为背景或贴图。

| 文件 | 内容 |
| --- | --- |
| room.png | 固定 3D 书房首页 |
| editor.png | 书与笔输入与分页 |
| metadata.png | 标题、标签、书架与次级操作 |
| lectern.png | 独立只读讲台工作台 |
| shelves.png | 书架分类与存放 |
| search.png | 全文搜索 |
| archive.png | 归档箱 |
| jukebox.png | 19 张音乐唱片的选择界面 |
| pause.png | Esc 暂停菜单 |

画面来自 Java 1.21 本地资源与本项目独立场景布局。游戏素材仍保留其原版权，截图不是可再分发的原版资源包，也不是原版游戏运行截图；不要将画面中的纹理或道具截取后标为项目原创资产。

维护者检查中文正文、像素界面和场景构图后公开。截图未包括设置中的本机数据路径；没有上传数据库、音频或提取纹理。
