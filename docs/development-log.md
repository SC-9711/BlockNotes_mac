# 项目开发日志

本日志记录已发生的实现与验收，不把规划当作已完成。下列短哈希来自保留在本机的开发历史；公开仓库从清理后的源码建立初始提交，因此它们不一定是公开仓库可点击的 commit。

## 2026-10-09：笔记闭环与书房视觉

- `d871cf8`：建立 Electron 桌面壳、本地 SQLite、笔记创建、编辑、保存、书架、归档与检索的基础闭环。
- `d666219`：根据 Java 1.21 研究模型、纹理、GUI 与原声，调整书房空间、物品模型和图标；保留原版资源为忽略的本地包。
- `8ab46f4`：修正讲台独占方块与灯笼支撑；加入 Esc 暂停菜单、操作指引、可靠退出和持久化空白书页。
- `ecb3b09`：加入可点击的唱片机，最终只保留 Java 1.21 的 19 张原始音乐唱片。
- `b90cb9e`：精简首页 HUD，增加考虑遮挡的静态方块光照与原版音符反馈。
- `e0dfad2`：解决梯子共面频闪，补齐桌面支撑，核对原版讲台几何尺寸。

这些变更复用 Three.js、R3F、Tiptap 与部分 PrismarineJS 几何定义，没有引入角色漫游、完整游戏客户端或第二套编辑器。

## 2026-10-10：公开仓库与首次运行

- 用户确认仓库目标 tonniescj-hub/BlockNotes，并选择 MIT。补齐 README、贡献说明、版权来源、Issue/PR 模板、Windows CI 和源码审查。
- 增加公开包外围目录检查，避免 extraResources 意外携带游戏资源或个人数据。旧开发历史保留本机，公开初始源码不携带旧历史中的本机路径。
- 按新验收标准加入首次启动自动资源准备：下载 Java 1.21 官方原始文件，校验哈希，在用户可写目录生成像素字体和本地资源包，成功后原子启用。公开程序包不携带原版素材，不要求安装 Node 或 npm。
- 像素字体转换复用同一实现，固定字体时间戳；与实机演示字体完成字节一致性检查。
- 公共源码 CI 使用合成测试夹具，不在 Actions 下载或上传游戏素材。

本轮最终联网、打包、功能回归及发布结果见 github-release-2026-10-10.md；该记录完成前不把首次运行流程称为已验收。
