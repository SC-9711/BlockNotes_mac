# 图标与学习笔记演示交付

用户选定「书与笔」图标，已接入 Windows EXE、应用窗口与浏览器页签。原稿与各尺寸文件见 `docs/icon-design.md`。从实际 Windows EXE 提取的 32 px 图标已检查，确认不是 Electron 默认图标。

当前可运行版本：`release/icon-demo/win-unpacked/BlockNotes.exe`。保留整个目录；原版本地资源包仍在 `resources/minecraft`，未提交或公开发布。

## 演示内容

按用户授权，一次性改写日常数据库中原有的 19 篇空白 / 短测试笔记，保留笔记 ID 与创建时间，按版本条件更新并在同一事务中提交，没有清库。源文案见 `examples/study-notes.json`；内容为原创虚构学生记录，用于产品演示。

- 「大学课程」：离散数学、线性代数、数据结构、计组、操作系统、数据库、计算机网络、大学英语；8 篇在书架、1 篇小组汇报归档。
- 「考研与英语」：周复盘、高数错题、408、复习方法、阅读、词汇、写作、口语；9 篇在书架、1 篇月复盘归档。
- 共 17 篇在书架、2 篇在归档箱、39 个显式书页。长页继续由既有编辑器自动分页，实际屏幕页数随窗口尺寸变化。
- 讲台的初始最近阅读设置为「高数错题｜换元后别忘上下限」。日常文案包含自己的误解、订正、下次复习安排，不放产品宣传语或操作教程。

程序没有新增自动填充、自动覆盖或演示模式；以后照常创建、编辑和保存自己的笔记。

## 数据保护

改写前完成 `VACUUM INTO` 全量 SQLite 快照，验证 `quick_check=ok` 与原笔记数量，并另存旧格式 JSON。文件在 `%APPDATA%/blocknotes/backups/before-study-demo-*`。原数据保留在这两份备份中，具体路径记录在本机 `artifacts/delivery/icon-demo-2026-10-10/demo-data-result.json`。

本机学习文案备份：`artifacts/delivery/icon-demo-2026-10-10/学习场景笔记备份.json`，仍为 schemaVersion 1，可通过既有恢复入口合并。

## 验证

- `npm run check`、生产构建、34 项自动化测试通过。
- 最终 Windows 打包程序 10 项 E2E 通过，包含既有数据可靠性、音效、唱片、实体点击、保存与备份回归。
- 日常数据库实机截图 8 张；核对 19 篇笔记的标题、正文、标签、归属、状态和版本在读取、翻页、检索与容器查看后均未改变。8 篇课程 / 9 篇考研英语 / 2 篇归档，零页面异常。
- 检查时发现分页占位元素重新排版会触发只读编辑器的更新回调，造成相同正文重复保存和短暂「待保存」提示。已限制只读模式不提交更新，并新增独立回归验证翻页和窗口重排不会改变笔记版本。既有编辑功能不变。
- `verify-package` 验证 16 个打包文件与源文件一致、正确 Electron 入口、原版资源未进入 app.asar。
