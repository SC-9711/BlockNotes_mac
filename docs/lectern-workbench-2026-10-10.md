# BlockNotes：讲台工作台与书架删除

日期：2026-10-10。对应用户授权的方案 2，以及「新增书架之后无法删除」修复。

## 本轮行为

讲台拥有独立阅读界面：进入后镜头平滑移到现有 3D 讲台近景，左侧像素容器选择笔记、按书架筛选及搜索正文 / 标签，右侧使用原版书页翻页。选书栏可收起。包含归档笔记，隐藏回收区；空库不创建笔记。阅读及窗口排版不触发正文保存，末页不会新增。点击「继续编辑」回到书与笔，使用原有编辑、自动保存、标签、导出与归档功能。Esc 可靠关闭并恢复书房镜头。九格物品栏位置不变，弹窗期间禁止场景和物品栏输入。

自定义书架在「管理书架」中增加「删除分类…」。空书架经过确认删除；包含笔记时必须明确选择接收书架，包括归档和回收区的笔记都迁移，保留正文、分页、标签、创建时间和状态。同名分类按独立 ID 操作，不误删另一个同名分类。两个绑定 3D 场景的基础书架允许重命名，不提供删除。

## 数据与实现

- 删除和笔记迁移在单次 SQLite IMMEDIATE 事务内执行；任一写入失败整体回滚。
- 确认名称校验阻止陈旧删除；迁移提升笔记 revision，陈旧编辑不能覆盖迁移结果。
- 不更改数据库 v2 或 JSON schemaVersion 1；旧备份恢复继续合并，重复恢复去重逻辑保留。
- 讲台复用唯一 Tiptap 编辑器及现有 DOM 分页；增加相同正文更新过滤，防止排版造成虚假保存。
- 相机预设集中在 `src/minecraft/layout.ts`；场景不读写笔记。
- 本轮没有直接修改日常笔记。运行验证使用临时数据库；实机展示使用日常数据库的只读一致性快照，保留正在运行的旧程序。

## 使用和交付

本机程序：`release/lectern/win-unpacked/BlockNotes.exe`。从旧程序的 Esc 菜单「保存并退出」，再通过更新后的桌面快捷方式启动新版。整个 `win-unpacked` 文件夹须保留。默认数据目录仍为 `%APPDATA%\blocknotes`。
